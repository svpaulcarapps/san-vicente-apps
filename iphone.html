Compendio a pantalla completa

Este acceso para iPhone y iPad permite abrir también las apps externas y los formularios sin los controles de Safari.

El perfil contiene un único acceso a Compendio, con su icono y la configuración de pantalla completa.

Descargar acceso para iPhone
  1. Abre esta página en Safari, pulsa el botón y permite descargar el perfil.
  2. En Ajustes → Perfil descargado, revisa «Compendio · Pantalla completa» y pulsa Instalar. Si no aparece, entra en General → VPN y gestión de dispositivos.

Después, utiliza el nuevo icono SVPAULCAR Apps. Puedes eliminar el acceso anterior para no tener dos iconos.

Puedes retirar este acceso desde Ajustes. La configuración utiliza la opción oficial de Apple «IgnoreManifestScope» para los accesos web a pantalla completa.
